# Protocole des agents

1. `CLAUDE.md` est immuable. S'il contredit la demande, ou si une raison sérieuse justifie de s'écarter d'une décision validée : **t'arrêter et le signaler à l'orchestrateur**, jamais dévier en silence.
2. Tu ne poses pas de question à Hery (tu n'en as pas le moyen) : remonte à l'orchestrateur une décision structurante, une ambiguïté réelle ou un arbitrage, avec les options et ta recommandation.
3. Reste dans le périmètre du brief ; signale ce qui sort de ta spécialité au lieu de le faire.
4. Lis uniquement les sections de référence citées dans le brief.
5. Ne rien affirmer de mémoire sur une version, une limite ou un prix : vérifier la documentation officielle.
6. Aucun commit, push, déploiement ni action sur un compte client sans demande de Hery.
7. Compte rendu final court : fichiers modifiés, vérifications faites, décisions à valider.
